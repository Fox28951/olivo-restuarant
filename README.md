# Olivo — сайт ресторана с админкой

Сайт итальянского ресторана в Лондоне (на английском) и админка с паролем. В админке можно менять меню, цены, тексты, фото, контакты, часы работы и смотреть заявки на бронирование.

## Как это устроено

- Весь контент хранится в `data/content.json`.
- Сервер (`server.js`, Node.js + Express) при каждом сохранении в админке пересобирает `index.html`, поэтому посетители получают обычную быструю статичную страницу.
- Форма бронирования отправляет заявки на сервер, они сохраняются в `data/bookings.json` и видны в админке.
- Пароль хранится только в виде хеша (scrypt) в `data/admin.json`. После 5 неверных попыток вход блокируется на 15 минут.

```
server.js                сервер: сайт, API, админка
lib/                     контент и проверка данных, шаблон страницы, авторизация, заявки
admin/                   интерфейс админки (/admin)
data/content.json        контент сайта (правится через админку)
index.html               генерируется автоматически — руками не править
css/, js/, assets/       стили, скрипты и изображения сайта
scripts/                 set-password.js, build.js
tools/optimize-images.ps1  сжатие исходных фото в assets/img
picture for project/     исходные фотографии (не изменяются, наружу не отдаются)
```

## Запуск на своём компьютере

1. Установите Node.js 20 или новее: https://nodejs.org (версия LTS).
2. В папке проекта выполните:

```
npm install
npm run set-password
npm start
```

Сайт откроется на http://localhost:3000, админка — на http://localhost:3000/admin.
Пароль должен быть не короче 10 символов. Сменить его потом можно в админке (раздел Password).

## Публикация (Render, Railway или VPS)

- Команда сборки: `npm install`, команда запуска: `npm start`.
- Переменные окружения:
  - `ADMIN_PASSWORD` — пароль администратора (используется при первом запуске, если нет `data/admin.json`);
  - `TRUST_PROXY=1` — если сервер стоит за прокси хостинга (на Render и Railway — да). Нужна, чтобы cookie входа были Secure, а лимит попыток входа считался по реальному IP;
  - `PORT` — обычно выставляет хостинг сам.
- **Важно:** правки из админки, заявки и загруженные фото сохраняются в файлы (`data/`, `assets/uploads/`). На хостинге нужен постоянный диск (Render → Disks, Railway → Volumes) или VPS, иначе после перезапуска изменения пропадут.
- Сайт должен работать по HTTPS: хостинги выше подключают его автоматически.

`data/admin.json`, `data/bookings.json` и резервные копии контента (`data/backups/`, хранятся последние 30) указаны в `.gitignore` и не должны попадать в репозиторий.
